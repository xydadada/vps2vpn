# 统一用词（会员中心、管理面板、服务端消息）

2026-11-26 和客户端一起定的规则，客户端仓库的 `.agents/wording.md` 和这份一致。改用户能看到的文字时照这份来；要改规则，就两边一起改。

## 规则

- **空格**：中文和英文字母、数字之间空一格，比如「AI 专线」「5 Mbps」「3 天」。例外三条：
  - 日期不空格；
  - 数字和「%」之间不空格；
  - 全角标点前后不空格。
- **标点**：中文句子用全角标点；提到按钮名、页面名、设置项名时用「」括起来。
- **英文**：
  - 用 Sentence case，只有第一个词首字母大写；
  - 用美式拼写，比如 color、center；
  - 句子里提到按钮名时，放进英文双引号。
- **动词**：桌面端写「点击 / click」。
- **进行中的状态**：写成「X中…」/ “X-ing…”，用省略号「…」，不用三个句点。
- **人称**：称呼用户用「你」，不用「您」；不写口语，比如不写「的话」「搞」「连不上」，「连不上」改成「无法连接」。
- **日期**：
  - 一般写「11月26日」；
  - 不在今年的写「2026年11月26日」；
  - 带时间写「11月26日 15:00」；
  - 图表刻度可以写「11/26」。
- **流量**：显示 3 位有效数字，比如「90.9 TB」「1.23 GB」；额度是整数时不带小数，比如「共 100 TB」。

## 用词表

| 概念 | 中文 / English | 不再用 |
|---|---|---|
| 订阅的网址 | 订阅链接 / subscription link | 订阅地址 |
| 列表里的一个条目 | 节点 / node | 句子里泛指节点的「线路」 |
| 自动选节点的分组 | 智能线路 / Smart line、AI 专线 / AI line | 「线路」只出现在这类分组名里 |
| 用户自己的 VPS | 服务器 / server | |
| 运营面板的人 | 管理员 / admin | 服务提供者 |
| 账号的持有人 | 账号所有者 / account owner | 主人 |
| 会员自己看的网页 | 会员中心 / member center | 会员页 |
| 管理面板里的账号 | 用户 | |
| 从列表拿掉一台设备 | 移除 / Remove（只打标记，可以「恢复」） | 踢下线、删除 |
| 换链接让别的设备断开 | 让其他设备下线 / Sign out other devices | 踢掉 |
| 登录 | 登录 / Sign in | log in、login |
| 计费倍率 | 「2 倍」/ “2×” | ×2、2x |

## 设备行

会员中心和管理面板都用 `kit.js` 的 `deviceRow`：

- 设备名过长时用省略号截断；
- 第一行：「平台 · 版本 · IP」，版本号前面不加 v；
- 第二行：「最后在线 11月26日 15:00」；
- 列表表头：「同时在线 2 / 上限 3」。
