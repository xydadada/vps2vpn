# 管理面板、会员中心细节审查（2026-11-26，基于 0.2.49）

在本机开发实例（`tests/dev_server.py` + `tests/dev_seed.py`）上逐页截图审查：中英文 × 深浅色 × 桌面（1280）和手机（375），外加加载中、出错、悬停、焦点、空实例。截图很多（约 750 张），只存在维护者电脑上，不进仓库；这里只记结论。地址只用文档地址。

- **P1（第 1–6 条、第 42 条）**：0.2.50 已修，前后对比见 CHANGELOG 0.2.50。
- **P2 / P3**：排在 0.2.52。下面每条后面的「状态」在修完时更新。

## P1（0.2.50 已修，只留标题）

1. 手机上多服务器页的按钮被长错误标签挤到屏幕外。
2. 中文界面里直接显示英文服务端原文（同步错误、体检、邀请备注、500 页）。
3. 深色模式下 `url` / `datetime-local` 输入框没有样式。
4. 用密码登录会员中心后要刷新才看到管理员公告。
5. 会员中心加载失败时只剩一行灰字，没有「重试」。
6. 管理面板右边缘一条灰色竖影（关着的抽屉露出阴影）。
42. 一台子服务器缺字段（如 `hy2_port`）会让整个会员中心和订阅 500。

## P2 用词、一致性、易懂程度

7. **确认框写法不一致**。目标写法：问句标题 + 动词按钮（如「移除这台设备？」/「移除」）。
   - 管理面板：「清零流量」「更换订阅链接」「更换加入码」「重启代理服务」标题不是问句、按钮「确定」；批量操作「删除 · 10」看不出是 10 个用户；撤销邀请码标题只有「撤销」；删除反馈标题只有「删除」；重启代理服务没说明会断线几秒；「更换端口」标题用半角「?」。
   - 会员中心：「更换订阅链接」、撤销邀请码同样。
8. **「批准流量申请」弹窗**：会员的理由和操作说明用「·」拼在一起；说明写「留空 = 按申请的数量批准」，但框里已预填数量。
9. **用词表漏网**：口语（「不等了，直接删」「怎么修：去…点…」「着急的话」「记得续费」「删掉」「这些人」「有就填」「一键建好 VPN」等）；「其它」→「其他」；同一面板里「使用者 / 用户 / 会员」混用（用词表定为管理面板里的账号叫「用户」）。
10. **中文界面里的英文眉题**：OVERVIEW、USERS、MEMBERS、SERVERS、MONITOR、SETTINGS、SYSTEM、SELF-HOSTED VPN、ADMIN CONSOLE、LIVE。
11. **英文文案**：单复数（`2 account(s)`、`1 users`）；`as airports do`；子服务器叫 node 和订阅里的节点冲突；`Use another port` 和「更换端口」不对应；会员中心状态值小写（`active`、`not connected`）。
12. **日期和数字格式**：用户列表到期日写 `2026-12-05`；流量小数位不统一（`5.00 GB` / `10.0 GB`、「剩余 31.9 GB」挨着「可分出 30.92 GB」）；「90天」少空格；「17 分钟 前 · 版本 0.2.49 ·」多空格、多「·」；实时流量横轴「1.5 分钟」少「前」；每日用量图横轴 `10/28`、没有纵轴刻度。
13. **内部代号**：用户行「hysteria2」、服务器行「reality / hy2 / tuic」；反馈行小写 `android` / `windows`。
14. **App 名称和按钮**：会员中心写「小火箭」，管理面板写「Shadowrocket」；会员中心 7 个 App 按钮，管理面板详情只有 4 个。
15. **到期日**：手机版用户列表不显示到期日；快到期的人没有提醒色。
16. **管理面板移除设备没有确认框**（会员中心有）。能恢复，可选。
17. **同一页保存方式不统一**：「客户端更新」开关立即保存，同页其他项要点「保存」，外观一样。
18. **加入码一直明文显示**，卡片自己写着「相当于这台服务器的钥匙」。
19. **文字用了数字的等宽字体**：「还没有 App 拉取过」「35 分钟前」、抽屉备注、会员中心「永 久」「不 限 量」；不限量账号圆环中间写「∞ 已用」。
20. **深色模式下危险按钮像禁用**（暗红描边加暗底）。
21. **邀请码行的数字没有说明**（「0/5」、日期分别是什么）。
22. **手机上会员中心标志被挤成「vp…」**（密码登录后多了「退出登录」）。
23. **微信里的登录页提示「点击『复制订阅链接』」**，但登录页没有这个按钮。
24. **加载中没有提示**：管理面板只有很淡的「…」，会员中心空白，用户详情抽屉数据回来前不出现。
25. **用户列表每行一个橙色实心「订阅」按钮**，比真正的主按钮还抢眼。
26. **会员中心「账号安全」**：没设过密码时按钮却写「修改密码」；句号后多一个空格。
