# 项目目标和已定的决定

这份文档记的是用户定下的方向。时间靠后的决定覆盖靠前的。用户有新决定时，在这里补上，并注明日期。

## 项目是什么

- **服务端**（本仓库 `xydadada/vps2vpn`）：把自己的 VPS 变成一条私人 VPN。一条命令装好，包括面板、部署器、会员中心、管理面板、订阅、多台服务器、流量倍率、限速和降速、设备管理、一键反馈。
- **客户端**（`xydadada/vps2vpn-client`，分支 `vps2vpn`）：基于 FlClash 的 Windows 客户端。目前只发 Windows 版。
- **两者解耦**：
  - 客户端在别家面板（V2Board、SSPanel、普通 Clash 订阅）上也要好用。
  - 服务端提供的功能只是「增强」：没有这些功能时，客户端不报错、不留空白、不误导用户。
  - 客户端更新的主渠道是 GitHub Releases。面板的 `clientsync` 只是补充渠道。
  - 第三方软件（Clash、Hiddify、小火箭等）用订阅也要能用。

## 已定的决定

- Windows 安装包不做代码签名，用户不买证书。客户端的更新包带 Ed25519 的 `.sig` 签名文件。
- 客户端界面只有中文和英文两种语言。
- 维护者（AI）自己判断、自己审查、自己合并、自己发版，只有很重要的事才问用户。对用户说中文。
- 外部 AI 审查：可以开 PR 和 issue，不合并、不推主分支、不打 tag。我们逐条核实，自己写修复。
- 仓库设置的改动由用户决定，例如开启私密漏洞报告。
- 等用户决定的两项：入口服务器（链式中转），以及每台设备单独的凭据。选项写在 HANDOFF 第 0 节第 12 项。
