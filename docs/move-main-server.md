# 总控换机器（主服务器搬到另一台）

主服务器（总控）要换到另一台机器时，怎么让大家手里的订阅链接不用换。

## 订阅链接由什么组成

```
https://<域名或 IP>:<面板端口>/s/<每个人的 token>
```

- **token**：在备份里，恢复后不变。
- **地址**：有域名时用域名；没有域名时用服务器 IP。
- **面板端口**：装的时候随机选的。**从备份恢复时用的是新机器自己的端口**（为了让你恢复后还能打开面板），不是旧机器的。
- 会员页 `https://<地址>:<面板端口>/<会员页路径>/`：路径在备份里，恢复后不变。

所以要链接不变，新机器上**地址和面板端口都要和旧的一样**。

## 有域名：大家什么都不用做

1. 在旧面板「体检与维护」→「下载备份」。旧机器先别关。
2. 记下旧面板的端口（面板地址里冒号后面那个数，订阅链接里也是它）。
3. 在新机器上用**同一个端口**安装：

   ```
   sudo V2V_PANEL_PORT=<旧端口> bash -c "bash <(curl -fsSL https://raw.githubusercontent.com/xydadada/vps2vpn/main/install.sh)"
   ```

   端口被别的程序占着时，安装会停下来并说明，不会悄悄换一个。
4. 在新面板「从备份恢复」。域名、账号、流量、邀请码、会员页路径、管理员密码都跟着备份走；面板的登录路径用的是新机器的，按新机器安装时打印的地址登录。
5. 把域名的 DNS 改指向新机器。改好后在新机器上执行 `sudo vps2vpn cert` 马上申请证书（不执行的话面板也会自己重试，但之前失败过的话最多要等 6 小时）。在这之前，用 HTTPS 订阅的软件会报证书错误。
6. `sudo vps2vpn doctor` 全部 OK 以后，再关旧机器。DNS 生效要一段时间，期间有人还连旧机器，所以不要马上关。

用了多台服务器的：子服务器不用动。备份里有它们的地址和密钥，主服务器自己的身份也跟着备份走，新主服务器恢复后一分钟内就接着同步。旧主服务器关掉之前两边都会同步，不要让旧的一直开着。

## 没有域名：每个人都要换链接

订阅链接里写的是旧机器的 IP。旧机器一停，所有人的链接都失效，软件也拉不到新订阅，没有办法补救。旧系统 legend 就是这样：总控一停，所有人的链接一起失效。

能做的：

- **最好**：搬家前先弄一个域名，在旧面板设置里填上域名，再把**带域名的新链接**发给大家，等大家都换过去以后，再按上面「有域名」的步骤搬。这一步多花一次发链接，但以后再搬家、换 IP 都不用再发。
- **只能直接搬**：恢复备份后，在新面板「用户」页把新的订阅链接一个个发出去（token 没变，只是地址变了），会员页地址也要重新发。没收到新链接的人会一直连不上。

## 换 IP 也是同样的道理

云服务器换了公网 IP，面板会自动改成新地址，但没有域名时订阅链接本身写的是旧 IP，同样要重新发链接（`docs/logic-review.md` O-10）。有域名的只要改一下解析。
